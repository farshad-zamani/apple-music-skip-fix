# Apple Music Skip Fix 0.1.0

First public beta for Windows 11 x64 and Microsoft Store Apple Music.

- Guided Check → Protect → Refresh → Authorize → Verify → Result workflow.
- SHA-256 verified metadata backups and reversible ADI directory refresh.
- Graceful process closure, fixed-scope permission helper and interruption recovery.
- Old-download playback checks, audible confirmation and separate optional offline result.
- Synthetic demo, light/dark UI, keyboard support, compact layout and sanitized report export.
- Per-user installer and portable ZIP; no Python installation required.

Unsigned community software. Keep the portable folder intact and verify release hashes. This targets authorization-related skipping; it is not a guaranteed fix for every playback issue. See docs/TESTING.md for validation scope. No personal Apple data is included.
